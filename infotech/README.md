Стек: vue + vite + vuetify

Запуск: npm run dev

Проект развернут по урлу: https://infotech-test.vercel.app

Описание: сгенерированы типы в types/interfaces.ts, мок данные в mock-data.json и большая часть в папке db (с indexedDB вручную очень долго реализовывать). Остальное руками и шаблонный код из документации библиотек, разве что баги порой ловил с помощью ии. Приложение берет мок данные и 1 раз их записывает в indexedDB, далее имитирует запросы к бэку.
